# KaarYab Afghanistan

A modern opportunity finder platform built with **Next.js** that helps Afghan youth discover jobs, internships, scholarships, remote work, online courses, and career opportunities in one place.

> **Note:** This project uses **Demo Data** for educational purposes.

---

## Project Description

KaarYab Afghanistan is a modern web application designed to help Afghan youth easily discover career, education, and professional development opportunities through a clean, responsive, and user-friendly platform.

The application allows users to browse, search, filter, save, and manage opportunities including jobs, internships, scholarships, remote work, online courses, and training programs.

---

## Problem It Solves

Many opportunities for Afghan students and job seekers are scattered across different websites and social media platforms.

KaarYab Afghanistan provides one centralized platform where users can quickly find useful opportunities without searching multiple sources.

## How to Run Locally

Clone the repository:

```bash
git clone https://github.com/somaiamosadeq1212/next.js-final-project.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
